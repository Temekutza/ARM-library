## Сущности (Entities)

### 1. КНИГА (Book)
| Атрибут    | Тип данных    | Описание                    |
|------------|---------------|-----------------------------|
| **BookID** | INT (PK)      | Уникальный идентификатор    |
| Title      | VARCHAR(200)  | Название книги              |
| Author     | VARCHAR(150)  | Автор                       |
| Publisher  | VARCHAR(150)  | Издательство                |
| Year       | SMALLINT      | Год издания                 |
| Quantity   | INT           | Количество экземпляров      |

### 2. ЧИТАТЕЛЬ (Reader)
| Атрибут      | Тип данных    | Описание                    |
|--------------|---------------|-----------------------------|
| **ReaderID** | INT (PK)      | Уникальный идентификатор    |
| FullName     | VARCHAR(150)  | ФИО читателя                |
| Phone        | VARCHAR(20)   | Телефон                     |
| Email        | VARCHAR(100)  | Электронная почта           |

### 3. СОТРУДНИК (Employee)
| Атрибут        | Тип данных    | Описание                    |
|----------------|---------------|-----------------------------|
| **EmployeeID** | INT (PK)      | Уникальный идентификатор    |
| FullName       | VARCHAR(150)  | ФИО сотрудника              |
| Position       | VARCHAR(100)  | Должность                   |

### 4. ВЫДАЧА (Issue)
| Атрибут        | Тип данных    | Описание                    |
|----------------|---------------|-----------------------------|
| **IssueID**    | INT (PK)      | Уникальный идентификатор    |
| BookID         | INT (FK)      | Ссылка на книгу             |
| ReaderID       | INT (FK)      | Ссылка на читателя          |
| EmployeeID     | INT (FK)      | Ссылка на сотрудника        |
| IssueDate      | DATE          | Дата выдачи                 |
| ReturnDate     | DATE          | Дата возврата (NULL если не возвращена) |
| Status         | VARCHAR(50)   | Статус ("Выдано"/"Возвращено") |

---

## Связи (Relationships)

### ВЫДАЁТСЯ (Book — Issue)
- **Тип:** 1:N (один ко многим)
- **Описание:** Одна книга может быть выдана много раз
- **Обязательность:** Каждая выдача должна содержать книгу

### ПОЛУЧАЕТ (Reader — Issue)
- **Тип:** 1:N (один ко многим)
- **Описание:** Один читатель может получить много книг
- **Обязательность:** Каждая выдача должна быть связана с читателем

### ОФОРМЛЯЕТ (Employee — Issue)
- **Тип:** 1:N (один ко многим)
- **Описание:** Один сотрудник может оформить много выдач
- **Обязательность:** Каждая выдача должна быть оформлена сотрудником

    │─────────────│         │─────────────│         │─────────────│
    │ BookID (PK) │         │ReaderID (PK)│         │EmployeeID   │
    │ Title       │         │ FullName    │         │  (PK)       │

    ◆════════════◆          ◆════════════◆          ◆════════════◆

## Обозначения нотации Чена

| Символ | Значение |
|--------|----------|
| ╔══╗ (прямоугольник) | Сущность (Entity) |
| ◇◇ (ромб) | Связь (Relationship) |
| ○ (овал) | Атрибут |
| **Подчёркивание** | Первичный ключ (PK) |
| 1 | Один (кардинальность) |
| N | Много (кардинальность) |
| FK | Внешний ключ |
